## 需求解读

这是一个**大地图攻城演示**，不是完整策略玩法。流程是：点长坂坡「进攻」→ 技术部从己方基地出兵 → 抵达后开战 → 双方按固定节奏减员 → 守军归零则易主并播放胜利。

**阵营与城池**


| 物体           | 含义        | 归属                        |
| ------------ | --------- | ------------------------- |
| `TBase`      | 技术部基地（我方） | 己方，出兵点                    |
| `DBase`      | 策划部基地     | 敌方，本 Demo 只作为场景存在，不参与这次攻城 |
| `ChangBanPo` | 长坂坡       | 开战前归策划部；策划部人数归 0 后归技术部    |


**开战前**

- 长坂坡上有「进攻」按钮。
- 点击后立刻开战准备：按钮消失。
- 20 支技术部部队沿路线向长坂坡移动，要有错落感。
- **3～5 秒内陆续完成出城**（理解为：20 支出发完毕落在 3～5 秒窗口内，而不是整段行军只有 3～5 秒）。

**抵达后**

- **首支**部队到城下：长坂坡从和平变为战乱。
- 城上 UI 即时显示双方人数；策划部初始 **10**。技术部人数需求未写死，按 20 支出兵计为 **20**。
- 技术部停在城外，播放**假伤害跳字**。

**战斗过程（造假节奏）**

- 技术部每 **3 秒**减 1。
- 策划部每 **2 秒**减 1。
- 策划部归 0：长坂坡归属技术部，播放胜利。

参考视频 `Images_attachments/第一段.mp4` 当前工程里**没有这份文件**，视觉只能按文档文字做简化演示。

## 实现计划



### 1. 场景与可视区分

- 给三城上色：技术部蓝、策划部红，便于看出归属。
- 给 `ChangBanPo` 补 Collider（目前没有），方便挂世界 UI / 点击。
- 补 **Canvas + EventSystem**。
- 在长坂坡附近放行军终点（城外一点），避免部队钻进立方体里。



### 2. 数据与流程控制

扩展现有 `GameManager`，用简单状态机串整场 Demo：

`Idle → Marching → Siege → Captured`

职责：

- 绑三城 Transform、进攻按钮、人数 UI、胜利 UI。
- 点「进攻」：藏按钮，生成 20 支部队，错开出发。
- 首支到达：切战乱、弹出人数 UI、开始减员与跳字。
- 策划部人数到 0：改长坂坡归属、停战斗、播胜利。

城池用一个小脚本 `City`：阵营、和平/战乱、改色或简单特效。

### 3. 「进攻」按钮

- 世界空间 Canvas 挂在长坂坡上方（或屏幕空间跟随城池）。
- 文案「进攻」，点击交给 `GameManager`，然后隐藏。



### 4. 出兵与行军

- 简单部队 Prefab（小立方体/胶囊 + 移动脚本）。
- 从 `TBase` 附近生成 20 个。
- **出城错落**：每队随机延迟，使第 1 支出发和第 20 支出发间隔在 3～5 秒内。
- **路线**：`TBase → ChangBanPo 城外点` 直线为主，每队加横向随机偏移，形成错落，不用 NavMesh。
- 速度可调，行军时间独立于出城窗口。



### 5. 战乱与人数 UI

- 首支到达：长坂坡改战乱外观（例如变橙/红、或头顶「战乱」字）。
- 城上 UI：`技术部：N` / `策划部：M`，策划部从 10 起，技术部从 20 起，随减员刷新。



### 6. 跳字与减员

- 城外随机位置周期性弹出假伤害数字（如 `-1`），向上漂再消失。
- 开战起计时：每 3 秒技术部 -1（对应销毁/隐藏一支城外部队）；每 2 秒策划部 -1。
- 人数到 0 后不再继续减。



### 7. 易主与胜利

- 策划部为 0：长坂坡阵营改为技术部（改成蓝色）。
- 屏幕中央（或城上）显示「胜利」，可加短缩放/淡入。
- 跳字和减员停止。



### 8. 文件结构（拟）

```
Assets/Script/GameManager.cs      // 流程总控（已有，补逻辑）
Assets/Script/City.cs             // 城池归属 / 和平战乱
Assets/Script/ArmyUnit.cs         // 单支部队移动
Assets/Script/FloatingDamage.cs   // 伤害跳字
Assets/Prefab/ArmyUnit.prefab
Assets/Prefab/（可选）DamagePopup / BattleHUD
```

场景接线：`GameManager` 引用三城、按钮、UI、部队 Prefab、出城点、城外集结点。
