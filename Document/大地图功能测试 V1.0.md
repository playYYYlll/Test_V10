# 大地图功能测试 V1\.0

# 场景构建

- 有三个城池

    - 我方：技术部基地

    - 敌人：策划部基地，长坂坡（策划部占有）

- 长坂坡有一个交互按钮

    - 进攻



# 攻城

- 点击“进攻”按钮，开始进攻，按钮消失

    - 20支技术部部队沿着路线向长坂坡移动，要有错落感，在3\-5秒内陆续完成出城

    - 首支部队移动到长坂坡城下后，长坂坡从和平状态变为战乱状态

    - 在长坂坡上添加一个ui，即时展示双方部队人数，策划部初始人数为10

    - 技术部部队在城外，播放伤害跳字（造假即可）

- 过程

    - 技术部每3秒死掉一个部队

    - 策划部每2秒死掉一个部队

    - 当策划部守军人数归0，长坂坡归属技术部

    - 播放胜利
